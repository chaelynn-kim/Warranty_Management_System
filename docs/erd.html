Warranty Management System — ERD (테이블 형식)

물리 DB는 Firestore app-data/{docId} 문서입니다. 아래는 논리 테이블(엔티티) 형식 ERD입니다.

0. 저장소 매핑

논리 테이블 Firestore docId data 형태 설명
ExternalTestRecordexternal-test-records배열외부시험
WarrantyIssuanceRequestRecordwarranty-issuance-requests배열보증서 발행 의뢰
WarrantyRecordwarranty-issuance-records배열구 발행 로그
WarrantyPeriodDatawarranty-period-data객체보증연한
WarrantyGuideFileRecordwarranty-guide-file객체Warranty Guide
WarrantyCertificateTemplatesRecordwarranty-certificate-templates객체보증서 양식
WarrantyEmailMailConfigRecordwarranty-email-mail-config객체메일 수신인
PermissionConfigRecordwarranty-permission-config객체권한
WarrantyFileAttachment(임베디드)객체첨부 파일 메타

From To 관계 연결 키 / 방식
Firebase Auth PermissionConfigRecord N:M (논리) email ∈ roles.emails

WarrantyEmailMailConfigRecord WarrantyIssuanceRequestRecord 1:N (논리) {{requester_email}} = requesterEmail
WarrantyPeriodData WarrantyIssuanceRequestRecord 1:N (논리) companyWarrantyTermsLookupKey
WarrantyCertificateTemplatesRecord WarrantyIssuanceRequestRecord 1:N (논리) productItem + language → slot
WarrantyIssuanceRequestRecord WarrantyFileAttachment / Storage 1:N 첨부 JSON → storagePath
WarrantyRecord WarrantyIssuanceRequestRecord 1:1 이관 동일 id

3. Firebase Storage 경로 테이블

Prefix경로연결
warranty-attachments/ requests/{recordId}/{slot}/{fileId}-{name} 발행 의뢰 첨부
warranty-guide/ global/{fileId}-{name} Warranty Guide
warranty-certificate-templates/ {slot}/{fileId}-{name} 보증서 양식

※ FK* = Firestore FK가 아닌 논리/소프트 참조
